# Very-Lazy 環境變數配置範本
# 複製此檔案內容並設定環境變數

# ==================== Azure DevOps ====================
# Azure DevOps 組織 URL（也可改在 config.json 設 "azureOrg"，env 優先）
AZURE_DEVOPS_ORG=https://dev.azure.com/your-org

# ==================== Slack ====================
# Slack Bot Token (以 xoxb- 開頭)
# 取得方式：https://api.slack.com/apps -> 選擇你的 App -> OAuth & Permissions -> Bot User OAuth Token
# 注意：請勿把真實 token 寫進這個被 git 追蹤的範本檔。
# 平常使用建議走 config.local.json（程式會在你第一次輸入後自動存到那裡）。
SLACK_BOT_TOKEN=xoxb-your-bot-token-here

# ==================== 使用方式 ====================
# Windows PowerShell:
#   $env:SLACK_BOT_TOKEN = "xoxb-your-token"
#   $env:AZURE_DEVOPS_ORG = "https://dev.azure.com/your-org"
#
# 或者在系統環境變數中永久設定
